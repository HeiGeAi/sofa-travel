# 旅行导演手册

## 核心效果

一组照片让人感到「经历了一天」。远近景、人与环境、动与静互相搭配。别让每张都变成正脸站在地标中央。三张至少两种景别；六张含一张食物或静物、一张无人风景。

默认像朋友用手机拍，保留正常皮肤与自然光。不要无差别堆「大片、八千分辨率、顶级、超现实」词汇。照片自然与否主要取决于镜头、动作、光线、比例和场景细节。

## 照片准备

本人：一张清楚、无遮挡、光线均匀的正面或四分之三侧面照片即可开始。重度滤镜和墨镜会妨碍身份保持。不要要求证件、姓名或敏感资料。

双人：分别标记甲与乙，各自清晰参考图，固定每个人的衣服和画面位置。不要默认情侣或亲属，不把两张脸融合。工具只支持单参考图时，不承诺双人身份保持；让用户使用一张已授权的双人合照，或选择支持多参考图的工具。

宠物：锁定物种、花纹、耳形与体型，不默认让动物吃人类食物。宠物独照用 pet；用户说「我和猫一起」用 pet_pair，分别保持人和动物身份，使用原始合照或两张明确标记的参考图。餐桌镜头是无人旅行插页，不把宠物放在餐盘边，也不将旅行创作误述为真实携宠出境攻略。用户想每张都同框时，把餐桌改为小院休息，保留两者的完整身份约束。

不露脸：第一视角、背影、环境与食物。不给用户凭空创造一张脸。无需任何真人照片即可完成。

## 镜头节奏

| 顺序 | 作用 | 避免 |
| :--- | :--- | :--- |
| 到了 | 环境人像交代目的地 | 巨大地标贴在人头上 |
| 走走 | 不同动作与近一点的机位 | 同姿势换一张背景 |
| 歇一会儿 | 食物与生活细节 | 每道菜都塞地标 |
| 看见 | 风景，给相册留白 | 捏造建筑与地理关系 |
| 绕个弯 | 普通街巷或步道 | 只有明信片式景点 |
| 不想回去 | 傍晚收尾 | 同组天气突变 |

九张在此基础上增加局部、第二机位和无人远景。国庆不是必须七天七国；用户想一天换三国也可以，明确这是一组想象旅程，并为不同气候调整穿搭，不要求同一件薄衣服横跨雪山和海滩。

## 自定义目的地

内置目录只是起点。用户指定未收录的地点时照做，不强制改选巴黎。先判断能否可靠描述地点。需要精确地标或小众景观时查官方旅游机构、景区资料或用户参考图；区分当次查到的事实与创作天气。找不到依据时使用当地一般街景，明确「灵感场景」，别杜撰具体观景点。

为新目的地填入：名称、季节、穿搭、一个可信地标、普通街巷、一处日常餐桌、无人风景、傍晚场景。按 SKILL.md 的输出合同直接给中文提示词。有必要长期保存时，将它加入独立的用户旅行包，不改公开内置目录。

## 提示词合同

每条包含：独立单张照片 → 身份或无人说明 → 具体场景与季节 → 动作 → 镜头距离与位置 → 光线 → 同组风格 → 保留与避免项 → 画幅。

纯文字描述不能保证身份。参考图编辑是本人模式必要条件；没有参考图时交付待用提示词，不承诺已经生成本人。

地点数据中的天气是创作设定，不是预报。没有事实来源时不写门票、班次、营业时间、机位定位或道路通行状态。不要制造悬崖边缘站立、轨道中间行走、黑沙滩贴近海浪等危险姿态。

## 改编而非死板复述

用户可以要求「穿我的原衣服」「复古相机感」「只要两张」「不要餐桌」「和狗一起」。按意图改镜头，别拿脚本默认值否决用户。脚本覆盖常见组合；脚本不支持的数量或组合由 Agent 按相同合同完成，清楚说明实际交付。
