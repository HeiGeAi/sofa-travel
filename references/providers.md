# 生图与平台适配

## 能力先行

本技能不绑定模型名字、不提供 Key、不逆向官方网页。先识别当前宿主的工具：文生图、单参考编辑、多参考编辑、图像查看、本地文件写入。能力不足时用提示词路径继续。

| 环境 | 操作 |
| :--- | :--- |
| 豆包 | 在官方应用当前的图片生成或编辑入口上传参考图，再复制一张完整中文提示词。以当前 UI 为准。 |
| 即梦 | 在官方图片生成入口添加参考图，粘贴中文提示词，选择竖幅比例。参考强度等参数以当前模型为准。 |
| Codex 等原生生图工具 | 遵循工具自身的参考图协议，先查看本地参考图。每个镜头一张图；风景插页不附人物图。 |
| WorkBuddy | 不假设内置生图。能调用图像工具就调用，不能就交付中文旅行包；有文件写入能力时再生成本地相册。 |
| heige-image | 使用用户已有安装和配置，不复制密钥，不改全局设置。人物模式调用 edit.py；无人镜头用 gen.py。 |

平台入口与免费额度会变化。软件和提示词免费不代表第三方推理免费。没有亲自验证的平台不要标「已实测」。

## heige-image 适配器

本项目的 `scripts/generate.py` 只是调用用户已有的 heige-image 脚本，不实现另一套 API 客户端。Python 解释器可通过 `--python` 指定，Skill 路径通过 `--skill-dir` 指定。默认只检查依赖并显示将执行的计划，不联网。

```bash
python3 scripts/generate.py --trip output/kyoto-first-trip --skill-dir /path/to/heige-image --reference /path/to/portrait.jpg
```

用户已要求实际生图且宿主允许调用现有付费配置时，追加 `--execute`。默认只运行第一张，需要整组时显式用 `--shots all`。一次失败就停，已有图片保留。

```bash
python3 scripts/generate.py --trip output/kyoto-first-trip --skill-dir /path/to/heige-image --reference /path/to/portrait.jpg --execute
```

这条路线仍需要 heige-image 自己的依赖和可用配置。旧版本可能没有 edit.py。脚本发现缺失时会报出具体缺口并保留提示词。不要从只支持文生图的版本生成陌生人冒充用户。

提示词原文为中文，直接传入。脚本参数名保持技术原样，不影响最终提示词语言。输出仅在获得实际图片文件后导入，保留哈希和尺寸。它不代替目视检查。

## 参考图角色

只有原始人物图：用于身份；场景由中文提示词描述。

原始人物图加已认可成片：前者用于身份，后者仅用于穿搭和影像风格。提示词明确角色，避免引擎把成片当成第二个人。自动适配器第一版只传原始参考，不自动叠加辅助成片。

双人：第一张甲，第二张乙；不附第三张未说明用途的人脸。宠物独照：只传宠物参考。本人和宠物同框：一张清晰合照；支持多参考图时可第一张本人、第二张宠物。明确各图用途，工具只支持单图时使用合照。食物和无人风景：不传身份图。

## 状态

`prompts_only`：只有提示词。

`partial_images`：部分镜头已导入实际图片。

`images_attached`：全部镜头都有文件。仍需目视检查每张的身份、地标、肢体与融合。

照片来源为 `user_import`、`native_generation` 或 `heige_image`。来源是操作者声明，哈希与尺寸是脚本核验；不把它写成不可伪造的证明。
